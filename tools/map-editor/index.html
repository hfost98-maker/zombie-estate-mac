1. Align screenshot

Upload an in-game or reference screenshot. Drag the four handles to the north, east, south, and west edges of the 32×32 map diamond.

2. Export alignment

Then run in Terminal:

python3 scripts/screenshot_to_assets.py YOUR_IMAGE.jpg --corners corners.json --name ScreenshotMap --pack-atlas

3. Load generated map

After the script finishes, load the .map.json from tools/screenshot-import/ to edit in Map Builder and validate in 3D Preview.

Tips

  1. Use a clear full-map screenshot (like Manor).
  2. Lower --merge-threshold keeps more detail; raise it for fewer tiles.
  3. Always open 3D Preview before exporting to game.

Handles: top → right → bottom → left (map compass). Corners are saved for the Python asset extractor.
